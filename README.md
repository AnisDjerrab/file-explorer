# file explorer

A universal file explorer meant to work everywhere, in Linux, macOS, Android, Windows, iOS. 
It is built in tauri, with a javascript frontend & a rust backend, making it blazing fast.
It is still in early versions, with a lot of features to implement. Your contribution are welcome
Future goals include:
- A good support for rooted android devices to let users have a correct linux-like file explorer.
- Integration with windows, linux, macOS, and rooted android root service by launching a custom rust program in root that acts as a root helper.
